# My Write-up Kit

A utility tool designed to streamline the process of writing my own write-ups and blogs. It instantly generates URL-friendly slugs and standardized Markdown templates from simple input fields.

## Features

- **Slugify generator:** Instantly converts strings into URL-friendly slugs.
- **Template generator:** Dynamically creates standardized Markdown (`.mdx`)files for write-ups and blogs based on user input.
- **Content suggestions:** Built-in reference for common markdown snippets.
- **Premium interface:** A responsive dark-themed UI with one-click copy functionality.

## Getting started

To run the application locally:

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open your browser and navigate to the localhost port provided in the terminal (default is `http://localhost:5173`).
